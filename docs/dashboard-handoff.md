# لوحة إدارة البورتفوليو

## ما تم بناؤه

لوحة خاصة على `/dashboard` داخل مستودع الموقع نفسه، بتصميم داكن أزرق، Montserrat، شريط جانبي متجاوب وألواح ذات زوايا مقعّرة/معكوسة. المؤشرات تعرض أعداد المحتوى وحالة المراجعات الحقيقية، وليست تحليلات أو أرقام زيارات وهمية.

| القسم | التحكم المتاح |
| --- | --- |
| Projects | إضافة وتعديل وحذف وترتيب، حالة الظهور، Featured، التقنية والتصنيفات، الروابط، الصور ووصفها، الميزات والعمارة وبقية حقول دراسة الحالة |
| Blog | المقالات وبياناتها وتواريخها، الوسوم، كتل النص والعناوين والقوائم والاقتباس والكود، ترتيب الكتل والمقالات، معاينة المسودة، المراجعة والنشر |
| About | الهوية والدور والروابط وCV، المقدمة، الخبرات والتعليم والتدريب والمبادئ، Journey وProcess |
| Skills | مجموعات المهارات وعناصرها وترتيبها وصفوف الـmarquee؛ الأيقونات تتبع سجل الأسماء الحالي، والمهارات الجديدة لها fallback آمن |
| Home / Site copy | الصور المشتركة والتنقل والنصوص المسجلة للصفحة الرئيسية والأقسام وFAQ والفوتر والتواصل ورسائل الواجهة |
| SEO | العناوين والوصف والقالب وcanonical وحقول المشاركة وrobots ورمز التحقق العام من Google، دون كشف أسرار الخدمات |
| Media | مسار رفع وإدارة صور وPDF خاص، روابط ثابتة، وحماية الملفات المرتبطة بمسودات أو بمحتوى منشور |
| Inbox | قراءة الرسائل الحقيقية المخزنة وتغيير حالتها إلى مقروءة/مؤرشفة أو حذفها |
| Settings | سجل المراجعات واستعادة نسخة كمسودة وتصدير نسخة المحتوى، وليس إعداد الأسرار داخل المتصفح |

النصوص والبيانات تُدار من الحقول، لكن CSS وGSAP والـbreakpoints وبنية المسارات تبقى كودًا؛ اللوحة ليست محررًا لتنفيذ JavaScript أو تغيير تصميم الموقع عشوائيًا.

## الحفظ والنشر والخصوصية

**Save** يحفظ مراجعة خاصة في PostgreSQL ولا ينشرها. **Publish** ينشر المراجعة المحفوظة بعد تأكيد منفصل ويحدّث الصفحات وmetadata وJSON-LD وsitemap وllms من المصدر نفسه. لإلغاء نشر مقال أو مشروع: اختر Draft ثم Save ثم Publish لتطبيق حالة الظهور الجديدة على الموقع.

التعديلات المتزامنة تُرفض عند اختلاف رقم المراجعة بدل الكتابة فوق تعديل أحدث. استعادة المراجعة تنشئ مسودة جديدة ولا تتراجع بالموقع المنشور تلقائيًا. المقالات الأولية الثلاثة تحتفظ بوسم Initial draft وتبقى خاصة إلى أن يراجعها المالك ويحدد نشرها صراحة. تاريخ تعديل المقال يُختم من الخادم عند تغيير بياناته، ولا يتغير لمجرد حفظ جزء آخر من الموقع.

دخول الإدارة يعتمد Better Auth وGitHub OAuth وحساب المالك صاحب GitHub ID `167328383` فقط؛ لا توجد صفحة تسجيل عامة أو كلمة مرور افتراضية أو مسار دخول تجريبي. كل API إدارية ومعاينة محمية من الخادم، مع فحص Origin للطلبات المعدّلة. مفاتيح OAuth وقاعدة البيانات والتخزين ليست جزءًا من المحتوى القابل للتصدير.

ملفات Blob خاصة. رابط الملف لا يصبح متاحًا للعامة إلا إذا استُخدم في المحتوى المنشور؛ الملفات الخاصة بالمسودة تتطلب دخول المالك. لا يمكن حذف ملف مرتبط بمحتوى محفوظ أو منشور. الحذف يسجل علامة دائمة قبل تنظيف التخزين؛ حالة `deletion-pending` قابلة لإعادة المحاولة إذا انقطعت إحدى الخدمتين.

## الحالة التشغيلية — مهم

التنفيذ اجتاز اختبارات حفظ فعلية على PostgreSQL محلي معزول ومراجعة حماية مستقلة. **لم يتم تفعيل وصول حسابي Neon وVercel في هذه المهمة، ولم يتم اختبار OAuth أو رفع Blob على حسابات الإنتاج.** لذلك لا يصح اعتبار الدخول والحفظ والرفع على الموقع العام جاهزين بعد.

`CMS_ENABLED` معطّل افتراضيًا. هذا يحافظ على الموقع الحالي وبياناته المعتمدة حتى لو كانت قاعدة رسائل التواصل متصلة بالفعل، وتبقى الإدارة مغلقة إلى أن يكتمل الإعداد. بعد التفعيل، خطأ قاعدة البيانات لا يعيد نشر بيانات أصلية قد يكون المالك ألغى نشرها.

## خطوات التفعيل الفعلي

1. ربط قاعدة Neon/PostgreSQL المستهدفة والتأكد من نسخة احتياطية وسجل الترحيلات. راجع الترحيلين الإضافيين `0001_early_next_avengers.sql` و`0002_mixed_doctor_strange.sql`. لا تعِد إنشاء جدول التواصل إذا كان موجودًا خارج سجل Drizzle؛ يجب تسوية سجل الترحيل أولًا.
2. تطبيق الترحيلات المراجعة عبر الإجراء المعتمد للمشروع. لا تشغّل سكربتات الاختبار على Neon أو قاعدة مشتركة.
3. إنشاء/تحديث GitHub OAuth App بعنوان callback: `https://theseif.vercel.app/api/auth/callback/github`. الإذن المطلوب هو بيانات الملف والبريد اللازمة للدخول، وليس صلاحيات إدارة المستودعات.
4. وضع `DATABASE_URL` و`BETTER_AUTH_SECRET` العشوائي القوي و`GITHUB_CLIENT_ID` و`GITHUB_CLIENT_SECRET` في متغيرات Vercel المحمية. المرجع هو `.env.example`؛ لا تُرسل القيم في المحادثة ولا تضعها تحت `NEXT_PUBLIC_*`.
5. ربط **Private Vercel Blob** وضبط `BLOB_STORE_ID` مع OIDC المناسب، أو `BLOB_READ_WRITE_TOKEN` من الخادم. لا تنشئ مخزنًا عامًا لملفات المسودات، ولا تشترِ خطة مدفوعة دون موافقة.
6. ضبط `SITE_URL=https://theseif.vercel.app` ثم `CMS_ENABLED=true` وإعادة النشر. نطاق الثقة الخاص بالدخول مستقل عن canonical القابل للتحرير في SEO.
7. تسجيل دخول المالك الحقيقي والتحقق من callback، حفظ مسودة غير منشورة، معاينتها، ونشر تغيير صغير متعمد، ثم رفع ملف والتحقق من خصوصيته ودورة حذفه. هذه الخطوة الحقيقية لم تُنفذ بعد.

تفاصيل المصادقة في `docs/dashboard-auth-setup.md` وتغطية الحقول في `docs/cms-content-coverage.md`. اختبارات الإدارة تمنع الاستهداف غير المحلي وتستخدم جلسات موقعة عبر الحارس الحقيقي، وليست bypass في التطبيق. نجاحها لا يعادل نجاح تسجيل الدخول الخارجي.

## الأدلة

نتائج repository في `docs/checks/cms-repository-results.json`، ومراجعة الكود في `docs/checks/dashboard-review.md`. اختبار API/المتصفح النهائي يسجل حالة الاكتمال ونتائجه في `docs/checks/dashboard-results.json`، وتُراجع نتائج SEO والتنقل العام بعده. لقطات Dashboard هي من بيئة الاختبار المحلية، وليست دليلًا على تفعيل خدمات الإنتاج.

فحص الوضع المعطّل مسجل في `docs/checks/cms-disabled-gate-results.json`: الموقع وllms يستجيبان بنجاح مع قاعدة غير متاحة، بينما الإدارة والمصادقة ترجعان 503 وDashboard تحمل noindex. `CMS_ENABLED=false` مخصص لمرحلة ما قبل التفعيل؛ بعد اعتماد CMS لا تستخدمه بديلًا لإلغاء النشر، بل طبّق حالات Draft/Publish من اللوحة نفسها.

### نتيجة التحقق النهائية

- نجح production build وTypeScript وESLint دون تحذيرات.
- نجح 23 فحصًا فعليًا على PostgreSQL محلي معزول للحفظ والمراجعات والخصوصية والتعارضات وحذف الملفات القابل للاستكمال.
- اكتمل 46 فحص API/واجهة دون إخفاق: حفظ وإعادة تحميل، نشر وإلغاء نشر slugs جديدة، رسائل inbox، حماية المالك، CSRF، المعاينات، إلغاء تأكيد النشر والملاحة المحمولة. لا تجاوز أفقي عند 390 و768 و1920px ولا أخطاء JavaScript في Dashboard.
- فحص SEO بلا إخفاقات، وفحص الصفحات العامة والتنقل والتنظيف والحركات والنسخ المخفّضة بلا إخفاقات متبقية؛ تم تصحيح توقع اختبار قديم كان يفترض تأجيل Journey رغم أن تكديسه المقبول يهيئ هندسته مبكرًا منذ النسخة السابقة.

هذه أدلة اختبار محلية للكود، وليست إثباتًا لتفعيل الدخول أو الحفظ أو التخزين الخارجي على حسابات الإنتاج.
