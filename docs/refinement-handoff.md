# تقرير تنقيح بورتفوليو سيف أيمن

**التاريخ:** 29 أكتوبر 2026

**النتيجة:** تنقيح فعلي للكود القائم، دون إعادة كتابة بنية التطبيق، ودون نشر أو دفع إلى مستودع GitHub الأصلي. النسخة متاحة في **Preview** لهذا المشروع.

## التغييرات المرئية

أُعيد تكوين **Featured Projects** كعرض تحريري داكن بصور كبيرة وعلاقة متعمدة بين الصورة والمحتوى، مع عكس موضعهما في المشروع الثاني. حُذفت قوائم التفاصيل المتنافسة والـbadges التقنية؛ بقي رقم المشروع والعنوان والتصنيف والوصف المختصر، والتقنيات كنص ثانوي، والأفعال الموثقة فقط. أُبقي مسار التمرير الأفقي العامل، ودعم نقل التركيز بالكيبورد إلى المشروع الموجود خارج الشاشة، والتخطيط الرأسي للشاشات الصغيرة أو reduced motion.

أصبحت **More Projects** مجموعة مستقلة ومضغوطة من ثلاثة مشاريع، بتخطيط موحد: عمود واحد على الهاتف، عمودان على التابلت، وثلاثة على سطح المكتب. أُزيلت الحاويات المتداخلة والاستثناء الذي كان يحول البطاقة الثالثة إلى صف مختلف. الصور بنفس نسبة 16:10؛ Nabd Masr يحتفظ بمرئي تحريري موسوم بأن المعاينة مقيدة، لا بصورة منتج مختلقة.

تحولت **Journey** إلى أربعة فصول تحريرية مفتوحة، مع فهرس جانبي ثابت وأرقام واضحة وعلاقة مباشرة بين المرحلة النشطة والنص ومعلوماتها الداعمة. حُفظت مراحلها ومعلوماتها الأصلية. استُبدل تراكب البطاقات بثلاثة tweens بخط تقدم واحد يعتمد المواضع الفعلية للفصول، ويتقدم ويرجع مع التمرير.

تحافظ **Process** على Discover → Design → Build → Ship، لكن بأرقام كبيرة ومرحلة قراءة مركزية وخط Light Blue رفيع على خلفية داكنة. أُزيلت الأيقونات الدائرية والبطاقات البيضاء وشرائح المخرجات. التخطيط المضغوط يعرض المراحل الأربع كنص متصل، مع تقدم عكوسة للحالة النشطة.

أُدمجت حركة **Hero** في timeline واحد داخل البنية الحالية: الدور والمعلومات الداعمة، كشف سطري الاسم، الفقرة والأفعال، ثم كشف الصورة بقناع. الأفعال تكتمل عند نحو 0.92 ثانية، وتبدأ الصورة بعد ذلك عند 0.94 ثانية. خلفية Hero والانتقال الحالي إلى About احتفظا بوظيفتهما، ولا توجد حركة تخطيط أو إخفاء ثابت للمحتوى في HTML.

## تقنية الدرع حول الصورة

الصورة الأصلية `public/images/seif-portrait.webp` لم تُعدّل، ولم تتغير أبعادها أو ألوان الجلد. استُخرجت من قناة alpha مساحة silhouette الأساسية، مع استبعاد بقايا الشفافية والنقاط المنفصلة، وحُفظت كقناع منفصل `portrait-silhouette.png` بحجم 1200 × 1600، وحجم ملف يقارب 16 KB.

يرسم SVG كفافًا فقط بواسطة توسيع alpha وطرح silhouette الأصلية، ثم يضيف إضاءة شعاعية محلية ووهجًا خفيفًا على الحافة. تتغير نقطة الإضاءة وعمق الحافة بمقدار ضئيل عبر DOM/CSS variables داخل RAF مجمّع واحد؛ لا تخزين لإحداثيات المؤشر في React state، ولا فلتر على الصورة/الوجه، ولا WebGL جديد. الهندسة محفوظة مؤقتًا وتُحدّث عند الحاجة، وجميع المستمعات وResizeObserver وRAF تُنظَّف. على اللمس وreduced motion تبقى نسخة ثابتة هادئة دون الحاجة إلى hover.

## سلوك المؤشر

المؤشر الأصلي لا يُخفى. يضاف follower صغير لا يستقبل أحداث النقر ولا يعطل التحديد أو الكيبورد، فقط على أجهزة fine pointer التي تدعم hover وبدون reduced motion.

| المنطقة | السلوك |
| --- | --- |
| المساحة العادية | حلقة/نقطة صغيرة هادئة بالقرب من المؤشر |
| الرابط العادي | توسع محدود للحلقة |
| الزر | حالة مستقلة أكبر قليلًا |
| رابط المشروع أو صورته القابلة للفتح | سهم اتجاهي واضح |
| سطح بطاقة غير قابل للنقر | حلقة preview متقطعة هادئة، دون سهم يوحي بنقر غير موجود |
| منطقة Featured الأفقية الفعالة | cue للاتجاه؛ لا ادعاء بأنها قابلة للسحب |
| CTA الأساسي في Hero | حركة مغناطيسية لا تتجاوز 4.5 px، وتعود للوضع الأصلي عند الخروج |
| حقول الإدخال والكيبورد | إخفاء follower أثناء التحرير أو استخدام الكيبورد |
| اللمس / مؤشر غير قادر على hover / reduced motion | تعطيل التتبع والمؤشر المضاف |

المستمعات مفوضة، والتحديثات مباشرة ومجمّعة لكل frame دون حلقة RAF خاملة مستمرة. تؤكد اختبارات تغيير المسار وmotion ثبات عدد المستمعات، وإزالة مستمعات الدرع عند مغادرة Home. يوجد مستمع مؤشر واحد مضاف فوق مستمعات Next.js الأساسية؛ جرى قياس الدلتا عند التعطيل وإعادة التفعيل بدل عدّ مستمعات الإطار باعتبارها تسربًا.

تم فحص 1440×760 و1280×800 و1024×768 و1920×1080 و768×1024 و390×844، بالإضافة إلى 1440×900 في فحوص سطح المكتب. في الحالات المختبرة كان horizontal overflow يساوي صفرًا، وHero CLS يساوي صفرًا، وفلتر الصورة الأصلية `none`، مع الاحتفاظ بـ`object-fit: contain`.

تقدم Journey في الفحص **01 → 02 → 03 → 04** وعاد **04 → 03 → 02 → 01**. Process عاد للمرحلة الأولى بعد التمرير العكسي، ويعرض مرحلة مركزية واحدة في التخطيط المثبت. نقل التركيز إلى آخر رابط Featured جعله داخل الشاشة. على reduced motion لا توجد ScrollTriggers أو pins، ويُعطّل follower وتتبع الدرع. إشارة console لإنشاء WebGL متوقعة فقط في سيناريو تعطيله عمدًا؛ ليست خطأ في التصفح العادي.

## الحدود الباقية

النتائج تخص السيناريوهات وأحجام الشاشة المذكورة، ولا تُعد وعدًا بقياس أداء كل جهاز فعلي. تأثير الدرع كفاف وإضاءة SVG خفيفة، وليس محاكاة فيزيائية كاملة للانكسار. بيانات المشاريع وصور مصادرها وروابطها الموثقة أُعيد استخدامها كما هي؛ لم تُجرَ مراجعة خارجية جديدة لكل رابط في هذه الجولة.

**لا نشر لهذه النسخة.** Neon وResend ما زالا غير مهيّأين؛ لوحة الإدارة والتكاملات الخاصة مراحل لاحقة لم يشملها هذا التنقيح. لم يُختبر إرسال خارجي أو تُكتب بيانات حقيقية، ولم يتغير مستودع GitHub الأصلي.
